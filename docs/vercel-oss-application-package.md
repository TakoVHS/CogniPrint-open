## 4. Short project description

> CogniPrint is an MIT-licensed open-source research framework for reproducible statistical text profiles and evidence-oriented synthetic-language research. It lets researchers measure compact interpretable text profiles, compare them, test their stability under controlled transformations, and preserve explicit boundaries between measured evidence, inference, attestation, and unknowns.

## 5. Why the project matters

> Text increasingly passes through chains of human editing, language models, translation systems, and publishing tools. Binary “AI vs human” labels are often too coarse for serious research. CogniPrint provides open research infrastructure for studying what measurable traces survive those transformations while explicitly refusing unsupported author, model, AI-origin, or forensic conclusions. The public project includes reproducibility scripts, validation artifacts, a mathematical manuscript, public-data diagnostics, an evidence dossier, failure boundaries, and an open blind-challenge protocol.

## 6. Why Vercel matters to CogniPrint

> Vercel hosts the public research-facing surface of CogniPrint. The project is moving toward a more useful Evidence Lab where researchers and developers can inspect the current scientific state, explore reproducible profile/perturbation demonstrations, access papers and evidence artifacts, and follow open challenges without installing the full local stack. Reliable public previews and deployment infrastructure are especially valuable because CogniPrint separates experimental work from production claims and needs reviewable, version-specific public surfaces.

## 7. How OSS credits would be used

> Credits would be used only for CogniPrint's open-source work: hosting the public research site and interactive evidence lab, preview deployments for reviewable UI/research-documentation changes, delivery of public reproducibility artifacts, open challenge pages, and infrastructure needed to keep the project accessible during external review and publication preparation. Credits would not be used for unrelated commercial projects or private customer workloads.

## 9. Community/open-source standards answer

> CogniPrint uses the MIT License, maintains a public Code of Conduct, documents data-license boundaries, records current scientific readiness as `descriptive_only`, and explicitly invites critique, replication attempts, negative results, and contributions that improve reproducibility. A contributor guide has been prepared to make these boundaries and the development workflow clearer for external contributors.

## 10. What makes CogniPrint different

> The differentiator is evidence discipline rather than a higher-confidence “AI detector” score. CogniPrint treats uncertainty and failure as first-class outputs. It distinguishes content-derived measurement from authenticated provenance, records explicit non-claims, and is building a public preregistration-oriented challenge designed to falsify as well as support future attribution hypotheses.
