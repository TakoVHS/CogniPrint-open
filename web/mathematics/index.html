Mathematical core

Language as a measurable object.

CogniPrint begins by treating a text sample as a point generated by interpretable empirical statistics. Geometry describes differences; information theory describes distributional structure; perturbation analysis describes motion.

φ(T) = [f₁(T), f₂(T), …, f₁₂(T)] ∈ ℝ¹²

The current v2 profile includes mean word length, type-token ratio, character entropy, word entropy, punctuation ratio, uppercase ratio, mean syllables per word, character-bigram uniqueness, Simpson diversity, digit-token ratio, mean sentence length and reading ease.

Geometry

Euclidean distance

d₂(a,b) = √Σ(aᵢ−bᵢ)²

Measures profile displacement in coordinate space. Interpretation depends on feature scaling and the empirical reference context.

Geometry

Cosine similarity

cos(a,b) = (a·b)/(‖a‖‖b‖)

Compares vector direction rather than raw displacement; it is a similarity statistic, not an identity certificate.

Information theory

Shannon entropy

H(X) = −Σ p(x) log₂ p(x)

Used to describe uncertainty/diversity in empirical character or token distributions.

Perturbation

Profile shift

Δφ = φ(T′) − φ(T)

The central dynamic object: how the measured profile changes after a controlled transformation.

The important distinction

A coordinate is an observation. A distance is a measurement. Neither, by itself, tells us who wrote the text or which model produced it.

Inference requires a benchmark, an in-distribution reference, calibration, uncertainty handling and a claim policy. CogniPrint deliberately keeps those layers separate.
